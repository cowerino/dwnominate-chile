# validation/ — making the reproduction claim falsifiable

`reproduce/` shows that this engine reproduces the published numbers. That is
only worth something if it could have come out otherwise. This directory
reintroduces a real defect, on purpose, and shows the reproduction failing.

    python validation/run_falsification.py

It copies `engine-faithful/` to a scratch directory, applies
`defect-alignment.patch`, builds **both** the clean and the defective engine with
the same toolchain, runs both over the panels in `data/`, reports the difference,
and deletes the scratch tree.

## The defect

`prepareRollCallData` reordered `voteCodes` into projection order while `coords`
stayed in natural order. So `voteCodes[i]` belonged to legislator
`sortedIndices[i]` while `coords.row(i)` belonged to legislator `i`, and the
NS>=2 CUTPLANE path, which consumes them together, classified a shuffled
pairing. Measured when found: **27.84 percent roll-call error against 5.58
percent** for the aligned optimum.

The canonical Fortran passes `XMAT` and `LDATA` in natural order and sorts
internally (`RSORT` plus `MVOTE(I)=MM(LLL(I))`, `CUTPLANE:4293-4296`), so natural
order on both sides is the faithful arrangement. The patch here restores the
misaligned version in twenty-two lines.

## Measured, 2026-08-22

Both engines built from the same source tree with the same compiler and the same
flags; the only difference is the patch.

| panel | clean | defective | defect delta |
|---|---:|---:|---:|
| `chile-static-p8` | -1138.778239 | -1606.242661 | **-467.46** |
| `chile-static-p21` | -6278.608009 | -7279.409946 | **-1000.80** |
| `chile-static-p23` | -13264.718199 | -14795.473301 | **-1530.76** |
| `us-sen90-static` | -15435.597141 | -16454.211015 | **-1018.61** |

Four panels out of four. Logs of both runs are in `logs/`, with machine paths
replaced by `<REPO>`, `<HOME>` and `<SCRATCH>` placeholders.

**Read this next to `reproduce/README.md`.** There, the SVD backend alone moves
the likelihood by 6 to 22 nats. Here the defect moves it by 467 to 1531. The two
effects differ by roughly two orders of magnitude, which is why the suite can
separate a real defect from a build-configuration difference — and why the
backend has to be recorded rather than assumed, so the small effect is never
mistaken for the large one.

Both runs above used `eigen_jacobi`, since the comparison is clean-versus-
defective rather than against the published numbers. Building both the same way
is deliberate: comparing a defective build against the committed results would
confound the defect with the backend.

## Separation criteria

Every threshold is placed **between the measured value on the defective build and
on the fixed build**, so the suite fails on the former and passes on the latter by
construction. Where the two builds do not separate on a statistic, that statistic
gets **no threshold** and is reported as informational. A threshold derived from
one run's output is not a threshold, it is a description.

**Tier 1, Senate 90:**

| statistic | defective | fixed | threshold | separates? |
|---|---|---|---|---|
| dim1 `r` | 0.9915 | 0.9907 | none, informational | no, and it inverts |
| dim2 `r` | 0.9870 | 0.9925 | >= 0.990 | weakly |
| mean 2D distance | 0.1299 | 0.1070 | <= 0.118 | yes |
| **amplitude** | **0.8705** | **0.9602** | **>= 0.915** | **yes, decisively** |

**Tier 2, five US Senates:**

| statistic | defective | fixed | threshold | separates? |
|---|---|---|---|---|
| per-period dim1 `r` | 0.987-0.992 | 0.992-0.995 | none, informational | no |
| **global-frame dim2 `r`** | **0.2179** | **0.7309** | **>= 0.50** | **yes, decisively** |
| global mean 2D distance | 0.2876 | 0.1865 | <= 0.237 | yes |
| amplitude | 1.0588 | 1.0552 | none | no |

The load-bearing clause on each tier is the one the earlier criterion did not
contain: amplitude on Tier 1, the global-frame second dimension on Tier 2. Both
earlier criteria tested the **first** dimension, in the frame that cannot see the
failure. That is the substantive point: a validation suite can pass throughout a
defect if every clause in it is blind to the axis the defect moves.
